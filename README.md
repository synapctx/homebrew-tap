# SynapCTX Homebrew Tap

Homebrew formulae for [SynapCTX](https://synapctx.com) tools.

## Install

```bash
brew install synapctx/tap/sctx
```

## Formulae

| Formula | Description |
| :--- | :--- |
| [`sctx`](https://github.com/synapctx/sctx) | Token-optimizing command wrapper for AI coding agents |

`Formula/sctx.rb` is generated by the
[sctx release workflow](https://github.com/synapctx/sctx/blob/main/.github/workflows/release.yaml)
on each stable tag, with checksums taken from the published release. Please do
not edit it by hand — the next release will overwrite it.
